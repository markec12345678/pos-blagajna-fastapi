# URY ERP System Overview

## Introduction

URY is a free and open-source restaurant management system powered by ERPNext. It provides a comprehensive solution for restaurants, cafes, and food service businesses to manage their operations from ordering to kitchen display to reporting and analytics.

## Features

Based on the Slovenian text description, URY offers:

- Complete restaurant management system based on the well-known open-source platform ERPNext
- POS system with offline capabilities for dine-in, takeaway, and delivery orders
- Kitchen Display System (KDS) for real-time order tracking
- Business analysis and profit/expense tracking
- Multi-device support (computers, tablets, smartphones)
- Menu and recipe management with inventory system integration
- Table management and occupancy tracking
- Support for multiple production units for multiple kitchens

## Installation Requirements

- Minimum Node version 19.20+
- Requires installed Frappe environment
- Installation via command line with bench commands
- Requires creating a new site for URY
- Requires installation of ERPNext and Frappe HR applications
